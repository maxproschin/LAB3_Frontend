# Лабораторна робота №3: SPA-додаток на React

### 📝 Завдання
Створити фронтенд-частину для блог-платформи у вигляді Single Page Application (SPA), яка взаємодіє з REST API.

### 🛠 Технології
* **React** (Functional Components, Hooks: `useState`, `useEffect`, `useContext`)
* **React Router DOM** (Маршрутизація)
* **Axios** (Запити до API)
* **Context API** (Керування станом авторизації)

### 🚀 Реалізований функціонал
1. **Головна сторінка (`/`)**: 
   - Відображення списку всіх постів.
   - Пагінація (перемикання сторінок через API параметри `page` та `limit`).
2. **Сторінка авторизації (`/login`)**:
   - Форма входу.
   - Імітація отримання токена та збереження стану користувача в `AuthContext`.
3. **Сторінка поста (`/post/:id`)**:
   - Динамічне завантаження даних конкретної статті за її ID.
   - Відображення коментарів, прив'язаних до цього поста.
4. **Навігація**: 
   - Глобальне меню для швидкого переходу між розділами без перезавантаження сторінки.

### 🔌 Налаштування та запуск
1. Встановити залежності: `npm install`
2. Запустити сервер розробки: `npm start`
3. Переконатися, що Backend API запущено на `http://127.0.0.1:8000`
